# CRUD Система управления объектами недвижимости

## 🎯 Реализованный функционал

### ✅ Backend (Django + DRF)

#### Система ролей и разрешений:
- **Роли пользователей**: `client` (клиент), `realtor` (риелтор), `admin` (администратор)
- **Кастомные permissions**:
  - `IsOwnerOrReadOnly` - владелец может редактировать, все могут читать
  - `IsOwnerOrAdmin` - владелец или админ могут управлять
  - `IsAdminUser` - только администраторы
  - `IsRealtorOrAdmin` - риелторы и администраторы

#### API Endpoints для объектов недвижимости:
- `GET /api/properties/` - Список всех объектов (публичный)
- `GET /api/properties/my/` - Объекты текущего пользователя
- `POST /api/properties/create/` - Создание объекта (авторизованные)
- `GET /api/properties/{id}/` - Детали объекта
- `PUT /api/properties/{id}/update/` - Обновление (владелец или админ)
- `DELETE /api/properties/{id}/delete/` - Удаление (владелец или админ)
- `GET /api/properties/my/stats/` - Статистика пользователя
- `GET /api/properties/stats/` - Общая статистика (только админы)

#### Дополнительные API:
- `POST /api/properties/{id}/favorite/` - Добавить/убрать из избранного
- `GET /api/properties/favorites/` - Избранные объекты пользователя
- `GET /api/properties/featured/` - Рекомендуемые объекты

### ✅ Frontend (Next.js + TypeScript)

#### Система ролей на frontend:
- **Роутинг с защитой** - проверка авторизации и ролей
- **Условная навигация** - разные пункты меню для разных ролей
- **Контекст авторизации** - глобальное управление состоянием пользователя

#### Личный кабинет пользователя (`/dashboard`):
- **Главная дашборда** - статистика, быстрые действия
- **Управление объектами** (`/dashboard/properties`) - CRUD интерфейс
- **Добавление объекта** (`/dashboard/properties/add`) - форма создания
- **Редактирование объекта** (`/dashboard/properties/{id}/edit`) - форма редактирования

#### Админ панель (`/admin`):
- **Общая статистика** - пользователи, объекты, заявки
- **Навигация по разделам** - управление пользователями, объектами, заявками
- **Расширенная аналитика** - детальные отчеты

### ✅ Ключевые компоненты

#### PropertyForm - универсальная форма объекта:
- **Создание и редактирование** объектов
- **Загрузка изображений** с предпросмотром
- **Валидация данных** на клиенте
- **Интеграция с API** через React Query

#### Система фильтрации и поиска:
- **Расширенные фильтры** по всем параметрам
- **Поиск по тексту** в названии, описании, адресе
- **Сортировка** по цене, площади, дате, популярности
- **Пагинация** результатов

## 🚀 Как использовать

### Для обычных пользователей:
1. **Регистрация/Вход** - `/auth/login` или `/auth/register`
2. **Личный кабинет** - `/dashboard` - статистика и управление
3. **Добавить объект** - `/dashboard/properties/add`
4. **Мои объекты** - `/dashboard/properties` - просмотр, редактирование, удаление
5. **Избранное** - `/favorites` - сохраненные объекты

### Для администраторов:
1. **Админ панель** - `/admin` - общая статистика системы
2. **Управление пользователями** - `/admin/users` (в разработке)
3. **Управление объектами** - `/admin/properties` (в разработке)
4. **Django Admin** - `http://localhost:8000/admin/` - полное управление
